🎮 GeminiStudio

Roblox Studio MCP Server with Google Gemini AI

GeminiStudio is a powerful desktop application that brings Google's Gemini AI directly into Roblox Studio. It integrates with the Model Context Protocol (MCP) to provide intelligent code assistance and agent capabilities for Roblox game development.
